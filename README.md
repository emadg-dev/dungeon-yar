# زروانیا | Zorvania TTRPG - پلتفرم چندکمپینی نقش‌آفرینی رومیزی D&D 5e

زروانیا یک پلتفرم همراه نقش‌آفرینی رومیزی (TTRPG) چندکمپینی و راست‌چین (RTL) به زبان فارسی است که بر پایه قوانین **D&D 5th Edition (SRD)** توسعه یافته است. این سامانه به طور کامل برای استقرار سریع، بدون سرور و سبک بر روی **Cloudflare Pages** همراه با پایگاه داده رابطه‌ای توزیع‌شده **Cloudflare D1**، سیستم احراز هویت سشن‌محور بدون اتکا به سرویس‌های شخص ثالث (Zero Third-Party Auth / No Firebase / No R2) و حالت آفلاین PWA طراحی شده است.

---

## ۱. اصول معماری و مدل چندکمپینی (Multi-Campaign Model)

1. **نقش‌ها بر اساس کمپین هستند (Campaign-Scoped Roles):**
   - کاربر در سطح پلتفرم تنها یک کاربر (`user`) یا مدیر سیستم (`admin`) است.
   - نقش‌های بازی (`owner` مالک، `co_dm` دستیار دانجن مستر، `player` ماجراجو، `spectator` تماشاچی) به ازای هر کمپین در جدول `campaign_members` نگهداری می‌شوند. یک کاربر می‌تواند در یک کمپین دانجن مستر و در کمپین دیگر بازیکن باشد.
2. **تفکیک هویت شخصیت از وضعیت بازی (Master Identity vs Play State):**
   - **شناسنامه جامع (`characters`):** نام، نژاد، تصویر چهره، توصیف ظاهری، پیشینه داستانی بخش‌بندی‌شده (با قابلیت مخفی‌سازی اسرار و تعیین بخش‌های عمومی برای هم‌گروهی‌ها) و گاه‌شمار رخدادهای ماندگار (`character_history_events`).
   - **وضعیت بازی در کمپین (`character_participations`):** کلاس، لول، میزان HP/AC، ویژگی‌ها، کوله‌پشتی، سکه‌ها، منابع، یادداشت‌ها و وضعیت تأیید ورود (`approved`, `pending_approval`, `changes_requested`).
3. **بسته‌های محتوا با منطق کپی هنگام مصرف (Copy-on-Use Content Packs):**
   - بسته‌های پیش‌فرض:
     - **«زروانیا» (`pack-zorvania`):** محتوای غنی دنیای فانتزی ایرانی زروانیا شامل کلاس‌ها، سلاح‌ها، هیولاها، آیتم‌ها، مکان‌ها و تقویم زروانی.
     - **«پایه ۵e» (`pack-srd-5e`):** ساختار استاندارد قوانین D&D 5e بدون متن‌های رسمی غیرمجاز (ویژگی‌های اساسی، اسکیل‌ها، تأس نجات، شرایط و انواع آسیب).
   - هنگام ساخت کمپین جدید، موجودیت‌های بسته محتوا به صورت عمیق کپی (Deep-clone) شده و به کمپین نو انتساب داده می‌شوند (`scope_type = 'campaign'`). هرگونه تغییر بعدی در کمپین به بسته مادر بازنمی‌گردد و تغییر بسته، کمپین‌های فعال را دستکاری نمی‌کند.
4. **سیستم رسانه درون دیتابیس (D1 Blob Media):**
   - تصاویر و آواتارها به عنوان باینری BLOB در جدول `media` درون D1 ذخیره می‌شوند (حداکثر ۱۵۰ کیلوبایت برای هر فایل، حداکثر سقف ۵ مگابایت سهمیه رسانه برای هر کاربر). هیچ نیازی به Cloudflare R2 یا باکت خارجی نیست.
5. **میز تاس مشترک و تاس پنهان:**
   - پرتاب‌های تاس کمپین در جدول `dice_rolls` ثبت می‌شوند. بازیکنان می‌توانند تاس عمومی روی «میز بازی» یا تاس محرمانه فقط برای دانجن مستر (`is_private_to_dm`) بیندازند.

## ۲. پایگاه‌داده Cloudflare D1 و مهاجرت‌ها (Migrations)

### راه‌اندازی دیتابیس جدید:
```bash
# ۱. ساخت دیتابیس D1 در Cloudflare
wrangler d1 create zorvania-db

# ۲. اجرای شمای کامل پلتفرم
wrangler d1 execute zorvania-db --local --file=./schema.sql
# یا برای سرور ابری اصلی:
wrangler d1 execute zorvania-db --remote --file=./schema.sql
```

### ارتقای دیتابیس موجود به نگارش چندکمپینی (Migration V2):
اگر از نگارش تک‌کمپینی قبلی زروانیا استفاده می‌کنید، فایل مهاجرت بدون از دست رفتن داده‌های موجود اجرا می‌شود:
```bash
wrangler d1 execute zorvania-db --remote --file=./migrations/002_multi_campaign.sql
```
همچنین اندپوینت ادمین `POST /api/admin/migrate-v2` امکان بررسی و تکمیل پیوند کاراکترهای قدیمی به جدول مشارکت و ساخت کمپین پیش‌فرض زروانیا را فراهم می‌کند.

## ۳. متغیرهای محیطی و سکرت‌ها (Environment Variables & Secrets)

در داشبورد Cloudflare به مسیر **Workers & Pages > Settings > Variables and Secrets** بروید (یا از طریق `wrangler pages secret put`):

| نام متغیر | نوع | توضیح |
| :--- | :--- | :--- |
| `ADMIN_EMAILS` | سکرت | ایمیل‌های مدیران پلتفرم (جایگزین `DM_EMAILS` پیشین؛ مقایسه بدون حساسیت به حروف بزرگ/کوچک) |
| `IP_HASH_SALT` | سکرت | سالت تصادفی طولانی و امن جهت هش یک‌طرفه IPها برای حفظ حریم خصوصی کاربران |
| `REGISTRATION_MODE` | متغیر | `"invite"` (پیش‌فرض، ثبت‌نام با کد دعوت) یا `"open"` (ثبت‌نام عمومی) |
| `ALLOW_CAMPAIGN_CREATION` | متغیر | `"anyone"` (پیش‌فرض، تمام کاربران می‌توانند کمپین بسازند) یا `"admin"` |
| `VITE_API_MODE` | فرانت‌اند | در صورت تنظیم روی `http` با اندپوینت‌های ابری ارتباط برقرار می‌کند؛ پیش‌فرض در نبود آن شبیه‌ساز محلی پرسرعت (`LocalApi`) با داده‌های پیش‌ساخته است |

## ۴. اندپوینت‌های کلیدی API چندکمپینی

### صفحه اصلی و خلاصه کاربر:
- `GET /api/home`: فهرست کمپین‌های من با نقش و وضعیت، شناسنامه‌های شخصیت، کدهای دعوت فعال و صف درخواست‌های تأیید (برای DM).

### کمپین‌ها:
- `POST /api/campaigns`: ساخت کمپین جدید (با امکان شبیه‌سازی از بسته زروانیا یا بسته خالی ۵e).
- `GET /api/campaigns`: فهرست کمپین‌های کاربر.
- `GET /api/campaigns/:id`: دریافت جزئیات کمپین، تنظیمات، آمار و نقش کاربر جاری.
- `PATCH /api/campaigns/:id`: ویرایش نام، توصیف، لحن، وضعیت، و تنظیمات قوانین.
- `DELETE /api/campaigns/:id`: حذف منطقی کمپین (`deleted_at`).
- `POST /api/campaigns/:id/members`: دعوت یا افزودن عضو.
- `PATCH /api/campaigns/:id/members/:userId`: تغییر نقش عضو (`owner`, `co_dm`, `player`, `spectator`).
- `DELETE /api/campaigns/:id/members/:userId`: حذف عضو یا خروج از کمپین.
- `POST /api/campaigns/:id/transfer-ownership`: انتقال بی‌بازگشت مالکیت کمپین به عضو دیگر.

### کدهای دعوت کمپین:
- `POST /api/campaigns/:id/invites`: صدور کد دعوت با نقش هدف، سقف استفاده و تاریخ انقضا.
- `GET /api/campaigns/:id/invites`: مشاهده کدهای فعال.
- `POST /api/campaigns/:id/invites/:inviteId/revoke`: ابطال فوری کد دعوت.
- `POST /api/invites/accept`: پذیرش کد دعوت و عضویت فوری در کمپین.

### شخصیت‌های جامع و مشارکت در کمپین:
- `GET /api/characters`: فهرست شناسنامه‌های جامع کاربر.
- `POST /api/characters`: ثبت شناسنامه جامع شخصیت جدید.
- `GET /api/characters/:id`: اطلاعات هویتی و پیشینه جامع.
- `PATCH /api/characters/:id`: ویرایش نام، پیشینه، ظاهر، اسرار دانجن مستر.
- `GET /api/characters/:id/history`: گاه‌شمار رخدادهای ماندگار شخصیت.
- `POST /api/characters/:id/history`: افزودن رویداد یا عطف تاریخی.
- `POST /api/campaigns/:id/join`: درخواست ورود شخصیت به کمپین (سطح آغازین یا سطح دلخواه تا سقف مجاز).
- `POST /api/campaigns/:id/participations/:partId/review`: تأیید، رد یا درخواست اصلاح شخصیت توسط DM.

### تاس مشترک کمپین:
- `GET /api/c/:campaignId/dice`: دریافت ۵۰ پرتاب اخیر میز بازی (با فیلتر شدن خودکار پرتاب‌های مخفی DM).
- `POST /api/c/:campaignId/dice`: ثبت پرتاب جدید با گزینه پرتاب پنهانی فقط برای دانجن مستر.

### رسانه‌ها (D1 Media BLOB):
- `POST /api/media`: بارگذاری تصویر (سقف ۱۵۰ کیلوبایت، بررسی حداکثر سهمیه ۵ مگابایتی کاربر).
- `GET /api/media/:id`: دریافت فایل تصویر با هدر `Content-Type` و کش مناسب.

## ۵. استقرار در Cloudflare Pages

1. مخزن کد را به Cloudflare Pages متصل کنید.
2. دستور ساخت: `npm run build`
3. دایرکتوری خروجی: `dist`
4. در بخش **Settings > Functions > D1 Database Bindings** متغیر `DB` را به `zorvania-db` متصل نمایید.
5. سکرت‌های `ADMIN_EMAILS` و `IP_HASH_SALT` را در بخش محیطی ذخیره کنید.
6. پروژه آماده استفاده بازیکنان و دانجن مسترها با تجربه کاربری غنی فارسی و ریسپانسیو موبایل است!
